El Subtitle Animator

Installer for DaVinci Resolve Studio

Main folder
The plugin folder was not found. Keep this app in the main folder, beside “El Subtitle Animator Plugin”, or choose the main folder.
Installed.
  1. Quit DaVinci Resolve completely and open it again.
  2. Choose Workspace › Workflow Integrations › El Subtitle Animator.
  3. Restart Claude Code so it picks up the MCP server and the commands.

The panel also works without the optional items: each engine can be installed later, here or from the panel when a feature first needs it.
