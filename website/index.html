Text+ presets

Animation Start and Animation Frames scale the whole animation: the per-letter motion, the delay between letters and the text's own keyframes. Set Animation Frames to 0 to go back to the preset's own timing.

MultiText presets

Each row has its own Start and End: Upper, Emphasis and Lower. The sounds and the highlight box follow those numbers, so moving a row moves everything tied to it.

Detected when you save

Animate a clip with keyframes in Resolve and save it. At the moment of saving I read the keyframes: for Text+ the frame the last letter lands on, for MultiText each row's first and last keyframe. You never type a frame number.

Detection reads keyframes, and it works best on the Boilerplate and the built-in presets. They have a known structure: named tools, a retiming node and timing controls, so every part I look for is where I expect it. A Fusion comp built from scratch is read on a best-effort basis, only if it happens to have that shape. Anything I can't read is saved exactly as you built it.
!

If you don't use the Boilerplate

  • Detection is best-effort. It needs one Text+ or MultiText at the top level of the comp, with the animation made of keyframes.
  • Motion driven only by expressions has no keyframes to read, so the slider stays at the preset's own timing.
  • Keyframes must count from the clip's first frame. Keyframes that start later give wrong numbers.
  • Animation inside a Group or Macro is not retimed.
  • Word-by-word typing presets have their own Typing Start and Typing Frames instead.
  • MultiText rows are only read from followers named UpperFollower, EmphasisFollower and LowerFollower. Rename them and the rows are not detected.
!

Limits of the Boilerplate itself

  • Keep the tool names: Template, Follower1, AnimTime, MediaOut1, the three row followers and Highlight. The app finds the parts by name.
  • Do not delete the Animation Frames or Seg controls on Template. The timing bar and the sounds depend on them.
  • The Text+ Boilerplate has one Follower. Keep the whole animation inside the first one to two seconds.
  • MultiText reads the three row followers only. The highlight box follows the Emphasis row and is not read on its own.
  • Effects added after the text, such as glitch or wiggle, keep their own speed and are not stretched.
  • On a very short clip the animation is cut at the clip's last frame, so keep the clip longer than the animation.

Requirements

Good to know.

What do I need?

DaVinci Resolve Studio on macOS (tested on 21.2), because Workflow Integration plugins are not in the free version. Python 3 (the copy bundled with Resolve works) and External scripting set to Local in Resolve's preferences.

Is this a preset pack?

No. It is a tool for creating, storing and customising presets. A starter set is included so you can see how it works, and you can edit, duplicate or replace every one.

Do I need Claude to use it?

No. The panel works on its own. MCP adds hands-off placement for people who want an AI to do the first pass.

How do I install it?

Run the included installer, restart Resolve, then open Workspace › Workflow Integrations › El Subtitle Animator.

Does it edit my footage?

No. It adds animated title clips and sounds on free tracks and switches off the plain subtitle underneath. Remove a placed clip and the subtitle comes back.

Does it detect my animation's length when I save?

Any animation made of keyframes can be read when you save it, but it works best on the built-in presets and the Boilerplate, which have a known structure. A comp built from scratch is read on a best-effort basis, and what I can't read is saved with its own timing.

Windows or Linux?

Currently macOS only.
